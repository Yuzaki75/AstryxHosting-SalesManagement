Members with this role, or the Manage Server permission, can use the admin slash commands below. Leave blank to allow only Manage Server.

Slash Commands

  • /plans — list available hosting plans (everyone can use this)
  • /stats [month] — total sales count and revenue (all time or per month)
  • /revenue [month] — revenue breakdown by payment method
  • /expiring [days] — subscriptions expiring soon (default 7 days)
  • /customer <name> — customer profile, spending, and recent purchases
  • /status — bot, database, and backup health

All commands except /plans require the configured Admin Role ID or the Manage Server permission. Replies are private to the person who ran the command. Create the bot at the Discord Developer Portal, give it the bot scope with no special intents, and invite it to your server. Registering slash commands happens automatically on save.
